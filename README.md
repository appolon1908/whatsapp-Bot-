# Codestra WhatsApp Commerce Bot

Python commerce service for independent businesses using Codestra's WhatsApp messaging platform.

Implementation is developed on scoped branches and reviewed before promotion. Provider delivery remains under the WhatsApp policy API and Middleware V3. Creating this repository does not activate messaging or install a production database.

The source architecture is [WhatsApp PR #23](https://github.com/appolon1908/WhatsApp/pull/23).
